Caveats — where the authority of the model stops

1. Proxy insensitivity. sigma = Z - Zeff is a linearized effective-charge accounting. The "inner partners screen universally" result (0.7914 vs 0.7924) may reflect the proxy being unable to distinguish 1s from 2p partners rather than a physical law; textbook screening rules already encode similar averaging.

2. Residual ambiguity. The +0.164 held-out residual could be ring coherence OR the proxy failing at complete subshells. The data cannot separate these; only the spectral channel can.

3. Reproducibility is not correctness. The reference shares published values and the same inversion with any replication, so a shared error would be reproduced. NIST verification remains the authority for every number shown.
