The brief (paste verbatim — do not include the reference panel)

Task. Eight isoelectronic ionization-energy tables are supplied below. Each table holds one electron configuration fixed and varies only the nuclear charge Z. For every member compute Zeff = sqrt(I·n²/13.6057) and σ = Z − Zeff, where n is the probe shell listed per table. Then:

1. Fit each of the seven training sequences (the table marked HELD OUT is excluded from all fitting) to σ = σ₀ + c/(Z−a), with the shift a free. Scan a below the smallest Z in the table, then refine. Report each RMS.

2. Derive the partner constants in this exact order (each from a different table):
  p1 = σ₀(Li-like) / 2  →  a(1s | inner)
  p2 = [σ₀(B-like) − 2·p1] / 2  →  a(2s | inner)
  p3 = σ₀(Be-like) − 2·p1  →  a(2s | same-ring)
  p4 = σ₀(C-like) − 2·p1 − 2·p2  →  a(2p | same-ring)
  p5 = [σ₀(Na-like) − 2·p1 − 2·p2] / 6  →  a(2p | inner)
  Held out: predict σ₀(Ne-like) = 2·p1 + 2·p2 + 5·p4, then report measured minus predicted.

3. Direction check (no fitting): at equal Z = 10 compare σ for Ne4+ in the C-like table against Ne5+ in the B-like table (one extra 2p partner), and σ for Ne6+ in the Be-like table against Ne7+ in the Li-like table (one extra s partner). Report which partner type screens more.

4. Universality: state whether the shifted form achieved RMS < 0.01 on all seven training sequences. Answer honestly from your own fits.

Partner composition (constant within each table):
Li-like: 2×1s inner  |  Be-like: 2×1s inner + 1×2s same-ring  |  B-like: 2×1s inner + 2×2s inner  |  C-like: 2×1s inner + 2×2s inner + 1×2p same-ring  |  Ne-like (held out): 2×1s inner + 2×2s inner + 5×2p same-ring  |  Na-like: 2×1s + 2×2s + 6×2p, all inner  |  Mg-like: those 10 inner + 1×3s same-ring  |  Al-like: those 10 inner + 2×3s same-ring (different subshell).

What this test can and cannot establish

Can: whether an independent implementation reproduces the constants, the held-out residual sign and size, the penetrating-s direction, and the honest universality verdict from the same data and method.

Cannot: (1) correctness — the reference shares the same published values and inversion; (2) whether the σ = Z − Zeff proxy is physically meaningful — its agreement across 1s and 2p partners may reflect insensitivity rather than a law; (3) the meaning of the held-out residual — a coherence term and a proxy failure for complete subshells predict the same number here.
