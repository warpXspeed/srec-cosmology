# Method

This note describes how the map is constructed and, more importantly, what it is and is
not claiming. It exists so the geometry can be evaluated on its own terms without the
conventional atomic data being confused for the interpretive framework, or vice versa.

## What the map is

A two-dimensional projection of the periodic sequence onto a logarithmic coil, with
closure rings placed at the noble-gas positions.

Two independent things are combined:

1. **The element sequence.** Z = 1 → 118 in strict atomic-number order. Not negotiable,
   not rearranged. Every node's position along the coil is its position in the sequence.
2. **A geometric ordering rule.** Radius expands geometrically, angle advances linearly,
   and rings are drawn at closure radii.

The first is standard chemistry. The second is the interpretive layer.

## What the map claims

**Weak claim (defensible, checkable):** the periodic table's group behaviour can be
expressed as a function of sequence distance to the nearest noble-gas closure, and this
reproduces the standard groups without a lookup table. Alkalis are one step past a closure,
alkaline earths two, halogens one before, chalcogens two, pnictogens three, noble gases are
the closures.

This is testable directly: enumerate the 118 elements, compute sequence distance to the
nearest closure, and compare the resulting partition against the conventional group
assignments. The classification in the map is generated by exactly that procedure, so the
comparison can be run against the source.

**Stronger claim (interpretive):** the closure structure is a resonance condition, and the
element classes follow from how far a given configuration sits from a completed resonance.
Under this reading, inertness is a full octave with no open slot to lock into; shedding is
a loose outer ring; a sink is an octave nearly full pulling to close. The map is a
visualisation of that reading.

The stronger claim is a framework position. It is not required to use the map, and the map
does not depend on it being accepted.

## What the map does not claim

- It does not claim the conventional atomic data is wrong. Masses, configurations and
  categories are standard reference values.
- It does not claim the coil is a physical orbit or a trajectory. It is a projection of an
  ordering, chosen because a spiral has no starting edge — which is what lets the f-block
  sit as a continuous detour rather than an inserted block.
- It does not claim the expansion factor `q` is a measured constant. `q` is a display
  parameter.
- It does not claim the node classes are new chemistry. The classes partition the elements
  the same way the periodic table already does; the claim is about *why* that partition
  takes the shape it does.

## Why a spiral

A rectangular table has to break its own layout to fit the lanthanides and actinides: a
floating block with an asterisk, inserted between two rows. A spiral has no edge to break.
The f-block becomes a detour along the path — the sequence coils inward and back out
before resuming — which is what the "core transition tensor" class is describing.

The second reason is that periodicity is a repeat in closure pattern, and a period is a
wave property. A coil makes the repeat visible as geometry rather than as a row that
happens to start over.

## Verification checks

Anyone evaluating this should run these:

1. **Monotonic radius.** For all `z`, `r(z) > r(z−1)`. The status line prints this on every
   render; it can also be checked in the source.
2. **Ring radii are outputs.** Every dashed circle's radius must equal `r(C_k)` for some
   closure `C_k`. There must be no independently positioned ring.
3. **Classification is derived.** The class of every element must be reproducible from its
   sequence distance alone, with no per-element exceptions.
4. **Group agreement.** Compare the generated partition against the conventional group
   assignments and count disagreements. The expected disagreements are the f-block, where
   sequence distance and group number do not correspond one-to-one.

Check 4 is the one that could falsify the weak claim. If the partition disagrees with
conventional groups in places that are not the f-block, the distance rule is wrong or
incomplete.

## Open questions

- **Preferred closure geometry.** Why six-fold closure dominates carbon chemistry while
  silicon and phosphorus prefer other closure angles is a property of the knot's internal
  count, not of the substrate alone. The map treats this as given; deriving it is open.
- **The f-block as a fold.** The tensor class is descriptive. A quantitative account of
  how many shells fold, and why fifteen, would strengthen it.
- **Ring spacing and the substrate measure.** The printed ring spacing follows the element
  count per octave. Whether the underlying interval is a specific ratio, and whether that
  ratio is recoverable from the closure positions, is not settled here.

## Related work in this repository family

The closure and saturation logic used here is the same logic implemented in the SRC
reaction engine, where assembly proceeds stepwise around a centre with a fixed number of
open boundary positions, terminates at saturation, and returns zero engagement for noble
gas partners. The engine is the checkable artefact; the map is the picture of why it works.
