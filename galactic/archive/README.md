# Research Archive

This directory preserves exploratory scripts, earlier analysis steps, and
superseded tools from the galactic-dynamics work. It is an audit trail.

**Archived does not mean "worthless," and it does not automatically mean
"falsified."** A toy simulation that fails to reproduce a galaxy does not,
by itself, falsify the physical idea behind it. A toy simulation that
produces a plausible-looking distribution does not show that nature uses
its rules. Each entry below states what the script actually did and what
its output can — and cannot — support.

## How to read this archive

Labels used in the inventory:

- **Exploratory analysis** — investigates a pattern or candidate
  relationship. Not, by itself, a test of a physical mechanism.
- **Toy / process demonstration** — illustrates specified rules in code.
  Its output describes those rules; it is not an observation of the
  universe.
- **Model test under stated assumptions** — compares a defined prediction
  with data or a numerical criterion. A failure applies to the tested
  formulation and assumptions, not automatically to every possible
  version of the idea.
- **Superseded** — retained for history; no longer the current analysis.
- **Reported / provisional** — an output was recorded, but the inputs,
  parser, calculation, or reproducibility have not been independently
  verified.

## Reported outputs versus verified findings

Some scripts were run during development and their terminal outputs were
recorded in conversation. Those outputs are valuable provenance, but a
transcript is not independent validation. Before citing any archived
number, document:

1. the exact script version or commit;
2. the input-file versions and selection criteria;
3. the units and column definitions;
4. the command used and the software dependencies;
5. whether the result was reproduced from a clean checkout.

Where a result has not been re-checked against the code and source data,
label it **reported** or **provisional** — never "confirmed."

## What the archived simulations do not establish

- That a simulated population matches real galaxy demographics.
- That a flat rotation curve emerges from a solved physical process.
- That electromagnetic currents or a substrate supply the required force.
- That the proposed medium exists with any measured density, viscosity,
  or coupling.
- That any cosmological model is proved or disproved.

What they *can* do: expose hidden assumptions, develop questions, and
show what a complete model would need to calculate.

## Reproducibility notes

- Archived scripts reference data files by relative path and may need
  path adjustments to re-run from the archive directory.
- Keep original scripts unchanged where possible. If a script is
  corrected, commit the change so the historical calculation remains
  recoverable.
- Identify synthetic inputs as synthetic.
- Do not delete a file because its interpretation changed; record the
  change in the project `LEDGER.md` instead.

## Data provenance

The SPARC source files and the 78-anchor clean database are maintained
at the top level of the `galactic/` module, outside this archive. Their
selection criteria and citations are documented in the module README and
in `build_clean_seed_db.py`. Archive entries here should not be read as
all using the same sample or the same data-processing pipeline.
